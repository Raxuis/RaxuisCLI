# Audit All Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Ajouter un audit web/DNS/TLS consolidé compatible avec les rapports existants.

**Architecture:** Un orchestrateur séquentiel appelle les services actuels avec un contexte partagé. La commande Cobra expose les options et applique le rendu et les codes de sortie actuels.

**Tech Stack:** Go 1.26.8+, Cobra, schéma de rapport v1.

## Global Constraints

- Aucune nouvelle dépendance ; aucun changement du schéma ou du parcours TUI.
- `--timeout` global : 60 secondes ; DNS/TLS : 10 secondes par requête/connexion.
- AXFR désactivé par défaut ; HTTP ignore TLS ; une IP ignore DNS.
- Préserver les constats et leurs identités ; échec partiel prioritaire sur le seuil de sévérité.

### Task 1: Orchestrateur

Files: `internal/audit/combined/audit.go`, `internal/audit/combined/audit_test.go`, `internal/audit/web/audit.go`.

Interface produite :
```go
func Audit(ctx context.Context, target string, options Options) (report.Report, error)
```
`Options` contient `Timeout time.Duration`, `Web web.Options`, `Nameserver string`, `AXFR bool`, et trois fonctions injectables reprenant les signatures des audits existants. La validation URL est partagée par `web.ParseTarget`.

- [x] Tester la validation avant réseau, les volets ignorés, le port HTTPS, les options, l’agrégation et l’annulation.
- [x] Implémenter la sélection des cibles, les collecteurs séquentiels, les statuts par volet et le rapport global.
- [x] Exécuter `go test ./internal/audit/...`.

### Task 2: Commande et contrats

Files: `cmd/audit/all.go`, `cmd/audit/all_test.go`, `cmd/audit/audit.go`, `main_test.go`.

Interface produite :
```go
func newAllCommand(runner combinedAuditRunner) *cobra.Command
```
Réutiliser `auditOptionsFromCommand`, `cmd.OptionsFromCommand`, `render.RendererFor`, `report.WriteFile`, `buildToolInfo` et `highestSeverityAt`. Retourner une `OperationalError` pour les échecs et une `PolicyError` pour le seuil atteint.

- [x] Exposer les options web existantes, `--nameserver`, `--axfr` et le timeout global.
- [x] Tester JSON/HTML, comparaison, refus de remplacement, options et codes 0/1/2 avec des collecteurs injectés et un serveur HTTP local.
- [x] Exécuter `go test ./cmd/audit ./...`.

audits, du catalogue et des commandes passent aussi sous Go 1.26.8. Le lint
